# The wiki added (2026-11-12)

## The ask

Owner, 2026-11-12: "Just noticed that agent-skills repo doesn't have a wiki can you please open a PR to include one, please reference chat history related to it for records, architecture, decisions, etc".

## What was written

In Luckgrid's shared wiki template (wiki-nest's `wiki-structure.md`), with only the folders there is content for:

- `wiki/README.md`: the entry, reading order, which page decides what, and the writing standard (IDs `AS-`);
- `architecture/`: [skill sources](../architecture/skill-sources.md) and [guest install](../architecture/guest-install.md);
- [program.md](../program.md), the roadmap, and [resources.md](../resources.md), the sources;
- `records/`: [STATE](STATE.md) and four records back-filled from the repository's history: [why it exists](2026-11-07-origin.md), [the first skills](2026-11-10-first-skills.md), [linked upstream skills](2026-11-10-linked-upstream-skills.md) and [the Workstation links](2026-11-12-workstation-links.md).

No `foundation/` folder: the root README and the architecture pages already say what the repository is for, and a folder of one page isn't created. No `records/decisions/` group: none of the repository's decisions is a numbered decision record yet; the decisions that bind it are listed in STATE.

The root README gained a pointer to the wiki and a rule for records. The repository gained `.rumdl.toml`, the same settings as site-system's and Workstation's, with `upstream/` excluded.

## Sources

- The repository: its four commits, agent-skills#1 to #3 with their descriptions and comments, `upstream.toml`, `scripts/check.sh` and `skills/herdr/UPSTREAM.md`.
- luckgrid/workstation at `30b10df`: GW-ADR-0014; Workbench's agent workflows and daily use; Groundwork's records of the guest agent environment, the agent tooling session and its review, and herdr-core; Workstation's consolidation review and STATE.
- The owner's project notes and past chats: the kickoff for the first guest session, and the reviews of agent-skills#2 and #3.

## How it was written

- Owner decisions are quoted as their records give them. Where a source names an account, this wiki describes it instead, since this repository is public.
- Nothing was taken from the review of candidate skills (`claude/agent-skills-shortlist.md`), which is in a project this session couldn't read.
- Every link and anchor inside the wiki was checked, and `rumdl check` 0.3.2 passed on `wiki/` and the README with the new `.rumdl.toml`. `scripts/check.sh` passed with the submodules initialised.
